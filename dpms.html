VE evaluation (Function vs. Cost)

For a chosen category, score each sourcing alternative on how well it fulfils the required function, then compare against cost to find the highest value index.

Value index = (Function score ÷ Cost in ₦'000) × 100

AlternativeFunction score (1–10)Unit cost (₦)Value index

The highlighted alternative carries the highest value index, because it meets the required function at the lowest relative cost, and is the one carried into the Development phase as the approved sourcing option.

Opportunity scanner

Ranks every category by savings potential if the highest value-index alternative is adopted. The scanner uses the same value-index formula, so it is a pure VE ranking and not a black box.
